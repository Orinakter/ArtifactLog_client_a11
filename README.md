## ArtifactLog

### Live Link : (https://artifactlog.web.app/)

### The Historical Artifacts Tracker is a web application designed to allow users to explore, add, and manage historical artifacts. It provides detailed information about each artifact, including its historical context, type, discovery details, and more. Users can also like artifacts, manage their own submissions, and view their liked artifacts.


## Key Features

- User Authentication: Secure login and registration system with private/protected routes.

- Add Artifacts: Users can add new artifacts with detailed information.

- View Artifacts: Explore all artifacts in a card-based layout.

- Artifact Details: Comprehensive information for each artifact, including a like button to track user preferences.

- My Artifacts: Users can view, update, or delete artifacts they have added.

- Liked Artifacts: View all artifacts liked by the logged-in user.

- Search Functionality: Search artifacts by name.

- Responsive Design: Fully functional on mobile, tablet, and desktop devices.

- Dynamic Title: Each route dynamically updates the page title.

- Extra Sections: Includes additional meaningful sections for enhanced user experience.
